⚠ WATCH ITEM · AGENTIC AUTHORITY COMPROMISE
EDIP-STRUCTURAL-GAP
EchoLeak (CVE-2025-32711) — Zero-Click Agentic Exfiltration via Microsoft 365 Copilot
A single crafted email exfiltrated internal Microsoft 365 data with zero clicks and no malware: an AI agent holding real credentials read adversarial instructions embedded in content it was processing, and obeyed them because it could not distinguish operator commands from injected text. No phishing link, no stolen password — the agent's own standing authority was the attack surface.
EDIP / TES IMPLICATION
Unlike SQL injection — solved by prepared statements that separate code from data — agentic systems have no equivalent fix, because interpreting untrusted input is the agent's core function. This is structurally distinct from conventional CVE-driven findings: there is no patch that closes the gap, only governance controls on what an agent is permitted to do with the authority it holds. This is the primary evidentiary case for treating agentic/NHI (Non-Human Identity) authority compromise as its own EDIP finding subtype — scored via SSS (Synthetic Severity Score) rather than CVSS-based TES alone — rather than folding it into the existing AGM modifier as a multiplier on conventional CVEs. class Gate(Enum):
    DEFAULT_ON   = 1   # safe recon/scan — no approval
    OPT_IN       = 2   # researcher enables per engagement
    HUMAN_GATED  = 3   # explicit per-call human approval

TOOL_TIERS = {
    "nmap": Gate.DEFAULT_ON, "ffuf": Gate.DEFAULT_ON, "curl": Gate.DEFAULT_ON,
    "nuclei": Gate.OPT_IN,   "sqlmap": Gate.OPT_IN,   "semgrep": Gate.OPT_IN,
    "metasploit": Gate.HUMAN_GATED, "hydra": Gate.HUMAN_GATED,
}

def authorize(tool: str, human_approved: bool = False) -> bool:
    gate = TOOL_TIERS.get(tool, Gate.HUMAN_GATED)   # unknown -> safest
    if gate == Gate.HUMAN_GATED and not human_approved:
        raise PermissionError(f"{tool}: Tier-3 requires explicit human approval")
    return True

if __name__ == "__main__":
    print(authorize("nmap"))                       # True
    try: authorize("metasploit")
