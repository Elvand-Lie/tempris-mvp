Section A · CVE-2026-46331 · Linux Kernel LPE
pedit COW — Linux Kernel Page-Cache Corruption
CVE-2026-46331 CVSS 7.8 LPE LINUX KERNEL tc/pedit FIM BYPASS POC RELEASED
What it does (need-to-know for correct EDIP intake)
Abuses a memory corruption bug in the Linux kernel's tc pedit (traffic control packet editor) module. Attacker with local user access corrupts the in-memory page cache of setuid-root binaries — executing modified versions while disk files remain untouched. File Integrity Monitoring (FIM) tools report clean. Working PoC is public. Unprivileged user namespaces + act_pedit module loaded = exploitable.

⚠ WATCH ITEM · AGENTIC AUTHORITY COMPROMISE
EDIP-STRUCTURAL-GAP
EchoLeak (CVE-2025-32711) — Zero-Click Agentic Exfiltration via Microsoft 365 Copilot
A single crafted email exfiltrated internal Microsoft 365 data with zero clicks and no malware: an AI agent holding real credentials read adversarial instructions embedded in content it was processing, and obeyed them because it could not distinguish operator commands from injected text. No phishing link, no stolen password — the agent's own standing authority was the attack surface.
EDIP / TES IMPLICATION
Unlike SQL injection — solved by prepared statements that separate code from data — agentic systems have no equivalent fix, because interpreting untrusted input is the agent's core function. This is structurally distinct from conventional CVE-driven findings: there is no patch that closes the gap, only governance controls on what an agent is permitted to do with the authority it holds. This is the primary evidentiary case for treating agentic/NHI (Non-Human Identity) authority compromise as its own EDIP finding subtype — scored via SSS (Synthetic Severity Score) rather than CVSS-based TES alone — rather than folding it into the existing AGM modifier as a multiplier on conventional CVEs. import json

CVE_DATA = [
    {"id":"CVE-2026-8451",  "cvss":8.8,"agm":1.0,"drf":1.1,"tef":1.2,"note":"SAML IDP memory overread — credential leak"},
    {"id":"CVE-2026-8452",  "cvss":8.8,"agm":1.0,"drf":1.0,"tef":1.1,"note":"DoS — Gateway/AAA availability"},
    {"id":"CVE-2026-8655",  "cvss":8.8,"agm":1.0,"drf":1.0,"tef":1.0,"note":"DoS — DNS/LB stability"},
    {"id":"CVE-2026-10816", "cvss":7.7,"agm":1.0,"drf":1.2,"tef":1.3,"note":"Unauthenticated file read — ESCALATE if mgmt exposed"},
    {"id":"CVE-2026-10817", "cvss":6.9,"agm":1.0,"drf":1.0,"tef":1.0,"note":"TCP Timestamp overread — low exploit likelihood"},
    {"id":"CVE-2026-13474", "cvss":8.7,"agm":1.0,"drf":1.0,"tef":1.1,"note":"HTTP/2 DoS — patch + set Http2SmallWndTimeout=30"},
]
TES_CAP = 10.0

def score(c):
    tes = round(min(c["cvss"]*c["agm"]*c["drf"]*c["tef"], TES_CAP), 2)
    if tes >= 9.0:   decision = "ESCALATE"
    elif tes >= 7.0: decision = "PATCH"
    elif tes >= 4.0: decision = "INVESTIGATE"
    else:            decision = "DEFER"
    return {**c, "tes": tes, "decision": decision}

results = [score(c) for c in CVE_DATA]
for r in results:
    print(f"{r['id']}  TES:{r['tes']}  {r['decision']}")
    print(f"  {r['note']}\n")
with open("netscaler_tes_scores.json","w") as f:
    json.dump(results, f, indent=2)
print("Saved: netscaler_tes_scores.json")
