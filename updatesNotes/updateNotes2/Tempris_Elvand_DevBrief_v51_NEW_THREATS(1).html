Section A · CVE-2026-46331 · Linux Kernel LPE
pedit COW — Linux Kernel Page-Cache Corruption
CVE-2026-46331 CVSS 7.8 LPE LINUX KERNEL tc/pedit FIM BYPASS POC RELEASED
What it does (need-to-know for correct EDIP intake)
Abuses a memory corruption bug in the Linux kernel's tc pedit (traffic control packet editor) module. Attacker with local user access corrupts the in-memory page cache of setuid-root binaries — executing modified versions while disk files remain untouched. File Integrity Monitoring (FIM) tools report clean. Working PoC is public. Unprivileged user namespaces + act_pedit module loaded = exploitable.

# rate_limit_middleware.py — add probe detection rules from fastapi import Request, HTTPException from collections import defaultdict import time # Sliding window rate limit config RATE_LIMITS = { "edip_score": {"requests": 20, "window_seconds": 60}, # 20/min per API key "edip_report": {"requests": 10, "window_seconds": 60}, "bulk_intake": {"requests": 5, "window_seconds": 60}, } # Probe pattern detection — flag if same client sends # systematically varied TES inputs within a short window PROBE_THRESHOLD = 15 # unique CVE inputs in 5 min = flag as probe PROBE_WINDOW = 300 probe_tracker: dict = defaultdict(lambda: {"cves": set(), "first_seen": 0}) async def detect_probe_attempt(api_key: str, cve_id: str): now = time.time() tracker = probe_tracker[api_key] if now - tracker["first_seen"] > PROBE_WINDOW: tracker["cves"] = set() tracker["first_seen"] = now tracker["cves"].add(cve_id) if len(tracker["cves"]) >= PROBE_THRESHOLD: # Log to audit trail, alert Sherie, return 429 await log_security_event("PROBE_DETECTED", api_key, cve_id) raise HTTPException(status_code=429, detail="Rate limit exceeded")
