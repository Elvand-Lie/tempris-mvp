# Tempris V2 Canonical Docs

This directory is the authoritative documentation library for V2. Documentation is compartmentalized by platform foundation or security module.

## Compartments

- [ASSETS & Collectors](ASSETS%20%26%20Collectors/README.md) — asset inventory, collector architecture, protocol, operations, and contract.
- [Tenancy & Control Plane](Tenancy%20%26%20Control%20Plane/TENANCY_CONTROL_PLANE_CANONICAL_GUIDE.md) — identity, tenant isolation, Organization, platform administration, and module entitlements.

Future modules such as SCOUT, SPECTRUM, and STRIKE should receive their own sibling directories when their contracts are implemented and frozen.
